Selected direction or hybrid definition:

> **Source Fold owns the master brand and expressive visual language. Evidence Register
> owns the product/evidence information architecture. Checkpoint 2 must build one new,
> coherent system from those strengths.**

Source Fold supplies the TryVit symbol and identity direction; package/source/provenance
metaphor; public and editorial expression; warm, human and premium character;
folded-label geometry; and the starting color, imagery, illustration, and brand-motion
language.

Evidence Register supplies observed → calculated/derived → contextualized → decision
ordering; explicit confidence, partial, unknown, and recovery states; compact responsive
density; comparable evidence rows; auditability and record-state mechanics; and rapid
product-detail and authenticated-application scanability.

This selection does not authorize pasting Source Fold's mark onto an otherwise unchanged
Evidence Register interface. Checkpoint 2 must define one palette, grid, type hierarchy,
wordmark system, icon grammar, spacing model, and motion language. It must not
automatically retain Evidence Register's complete cobalt/copper palette or generic
document mark, and it must not retain Source Fold's slower source-first composition when
that delays the score, confidence, main reason, or next action on mobile.
