Date: 2026-08-25. This is a public-record screening by a software implementation agent.
It is **not legal clearance, a freedom-to-operate opinion, or advice from a trademark
professional**.

## Searches performed

1. EUIPO eSearch plus basic search for `TRYVIT` returned one similar record:
   `TRYVITE`, EUTM `018026887`, figurative, registered, Nice classes 3, 5, and 35,
   filed 2019-02-22 and registered 2019-06-21. Repeating with `TRY VIT` returned the
   same single record. Class 5 and the close word construction make this result
   material enough to require professional assessment.
2. The Polish Patent Office e-Search exact query `TRYVIT`, across the selected public
   collections, returned “No results found which match your selection.” That result
   does not cover unindexed, pending, regional, international, common-law, company-name,
   domain, or marketplace conflicts.
3. WIPO's official Global Brand Database information page was accessible, but its
   interactive quick-search host was blocked by the local browser client. No WIPO
   result set is claimed.
4. EUIPO advertises image-similarity search. An upload attempt using the approved
   Source Fold identity board did not complete in the available browser tooling, so no
   authoritative figurative-similarity result set is claimed.

## Originality screen

The repository implementation uses code-authored geometry derived from the approved
Phase 5A.2 Source Fold concept. No copied logo file, external icon library mark, stock
image, or AI-generated bitmap is used on the landing. The visual grammar—folded tag,
square aperture, and reverse face—is still composed of common geometric ideas and is
not presumed exclusive.
